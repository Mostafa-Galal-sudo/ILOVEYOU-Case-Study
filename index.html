The message

It did not look like malware.

It looked personal. The subject created urgency; the sentence sounded like it came from someone you knew. The final disguise was a filename that appeared to end in .TXT while actually ending in .vbs.

The sample then used Microsoft Outlook and MAPI to repeat the same invitation to every contact it could reach. Social engineering was not a preface to the attack. It was the engine.

The disguise

“A love letter” was only the visible filename.

Windows hid the final extension. What looked like a text document was executable VBScript waiting for a double-click.

LOVE-LETTER-FOR-YOU.TXT.vbs

Execution

Four routines.
One chain reaction.

The script reads its own source into memory, then moves through a short, deliberate sequence. The red thread follows the order found in main().

01

Read itself

Turn the script into a copyable payload.

FileSystemObject opens the running script and stores every line in vbscopy. From this point, any writable file can become another copy. 

vbscopy = file.ReadAll
02

Replicate

Hide behind names that feel familiar.

Three copies land in Windows and System folders. Two imitate system components; one preserves the love-letter disguise.

  • SYSMSKernel32.vbs
  • WINWin32DLL.vbs
  • SYSLOVE-LETTER-FOR-YOU.TXT.vbs
03

Persist

Return whenever Windows starts.

Two registry values point back to the dropped scripts. A third value stages the secondary executable, WIN-BUGSFIX.exe.

Conclusion

The code was simple.
The context made it powerful.

ILOVEYOU succeeded by turning ordinary trust into infrastructure. A familiar sender delivered the lure. Familiar filenames hid the payload. Familiar software carried it onward. The worm did not need a sophisticated exploit when human curiosity could start the chain.

Static analysis only. The supplied script was read as text and never executed.
